# Matriz de cobertura inicial

Esta matriz é o contrato de distribuição para a expansão da base. Cada lote deve
ser pesquisado, validado pelo `scripts/validate_batch.py` e inserido somente após
checagem de gabarito, fonte, duplicidade e persistência.
